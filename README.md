# 🎮 SubDB.info — База региональных цен сервисов и подписок (в стиле SteamDB)

Небольшой, быстрый и удобный сервис для мониторинга и сравнения цен на цифровые подписки в разных странах мира (Турция 🇹🇷, Нигерия 🇳🇬, Аргентина 🇦🇷, Индия 🇮🇳, Казахстан 🇰🇿, Украина 🇺🇦, Польша 🇵🇱, США 🇺🇸 и др.).

## 🚀 Стек технологий
- **Backend:** Go (Golang) — сверхбыстрый REST API на стандартной библиотеке с конвертацией валют, сортировкой, фильтрацией и раздачей статики.
- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS + Lucide Icons.

---

## 🌟 Что умеет SubDB

1. **Каталог сервисов со SteamDB-дизайном:**
   - YouTube Premium, Spotify, ChatGPT Plus, Netflix, Xbox Game Pass, PlayStation Plus, Steam EA Play, Apple iCloud, Telegram Premium, Discord Nitro, GitHub Copilot, Crunchyroll и др.
   - Фильтры по категориям (Стриминг, Музыка, AI & Софт, Игры, Утилиты).
   - Поиск в реальном времени.
   - Сортировка по максимальной выгоде (% скидки от цен в США), цене от дешевых, алфавиту, популярности.
2. **Мгновенный пересчет валют:**
   - Поддержка переключения отображения в **RUB (₽), USD ($), EUR (€), KZT (₸), TRY (₺), UAH (₴), PLN (zł), GBP (£)**.
3. **Детальная страница каждого сервиса:**
   - Все тарифные планы (Individual, Family, Student, Duo, 4K и др.).
   - Таблица всех стран от самой дешевой к самой дорогой.
   - Бейджи сложности оплаты (🟢 Легко / 🟡 Виртуальные карты / 🔴 Местный ID).
   - Заметки и лайфхаки по оплате (какие карты подходят, нужен ли VPN).
4. **Матрица стран (Country Matrix View):**
   - Сводная таблица «Сервисы vs Страны» с зеленой подсветкой минимальной цены для каждого сервиса.
5. **Калькулятор экономии:**
   - Выбор персонального стека подписок и мгновенный расчет экономии в месяц и за год.
6. **Форма предложения актуальной цены:**
   - Возможность отправки правок и новых цен сообществом.

## 🏃 Быстрый запуск

### Вариант 1. Запустить готовый продакшн-сервер:
Дважды кликните по `start.bat` или выполните:
```powershell
cd backend
.\subdb-server.exe
```
Откройте браузер по адресу: **http://localhost:8080**

### Вариант 2. Запуск в режиме разработки (Hot Reload):
Дважды кликните по `dev.bat` или выполните:
```powershell
# Терминал 1 (Бэкенд Go):
cd backend
go run .

# Терминал 2 (Фронтенд React):
npm run dev
```
Фронтенд будет доступен на **http://localhost:5173** (автоматически проксирует API на 8080).
